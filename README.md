# MCHOL

> A fan-made High on Life mod: talking guns, Bounty Hunter armor with jetpack and alien worlds.

![Minecraft](https://img.shields.io/badge/Minecraft-26.1.2-62b47a) ![NeoForge](https://img.shields.io/badge/loader-NeoForge-e68c37) ![Release](https://img.shields.io/github/v/release/ArdinyoGitHub/mchol)

An unofficial, fan-made mod inspired by **High on Life**. Become an intergalactic bounty hunter in Minecraft.

## Guns
Kenny, Gus, Sweezy and Creature, plus alternate forms like Multiglob Kenny, Goop Suck Gus and Portal Sweezy.
Each one fires its own projectiles.

## Bounty Hunter gear
- Full **Bounty Hunter armor** set with a **jetpack** (bound to its own key)
- **BH9K** teleporter: open its menu to travel between the Overworld, the Nether, the End and the alien worlds

## Alien worlds
- **Zephyr Paradise**: two biomes, Zephyr trees, villages with their own Zephyr villager profession
- **Gatlus** and **Terenne**
- Blue Grass, Skyflower and Flameflower plants

## Building
Two new wood types, **Zephyra** and **Zephyra Blue**, with planks, stairs, slabs, fences, doors, trapdoors,
signs, hanging signs, boats and chest boats. Plus Zephyr stone and cobblestone.

## Creatures
Merk and Blue Myte.

All items are in the **High On Life** creative tab.

## Requirements

| | |
|---|---|
| Minecraft | 26.1.2 (release jar) — source tree already ported to 26.3 |
| Loader | NeoForge |

## Download

- [GitHub Releases](https://github.com/ArdinyoGitHub/mchol/releases)
- Modrinth / CurseForge pages are linked from the release notes once published.

Drop the jar into your `mods` folder (NeoForge only).

## Building from source

This is an [MCreator](https://mcreator.net/) workspace (`mchol.mcreator`) with some hand-written code.
Open it in MCreator and use *Regenerate code*, or build from the command line:

```sh
./gradlew build
```

The jar ends up in `build/libs/`.

## Reporting bugs

Open an [issue](https://github.com/ArdinyoGitHub/mchol/issues) with your mod version, Minecraft/NeoForge version and the log (`logs/latest.log`) if the game crashed.
